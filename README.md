# Clockvoyant ⏱️

The party game that tests your inner clock. One hidden clock, everyone adds time; go over the limit and you're out.

**Get it on Google Play:** https://play.google.com/store/apps/details?id=com.clockvoyant.app

The APKs under Releases are old test builds and are no longer updated. If you installed one, uninstall it before installing from Google Play.
